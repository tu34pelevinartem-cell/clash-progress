# Clash Progress

Статический трекер прогресса Clash of Clans. Сайт работает без сервера и регистрации. Снимки деревни сохраняются в браузере посетителя.

## Адрес сайта

https://tu34pelevinartem-cell.github.io/clash-progress/

## Публикация на GitHub Pages

Репозиторий использует GitHub Actions: изменения в main собирают и публикуют сайт автоматически. В Settings → Pages выбран источник GitHub Actions.

Скрипт scripts/prepare-assets.cjs собирает каталог _site: распаковывает справочник data/upgrades.json.gz и добавляет изображения из закреплённой версии clash-of-clans-data. Целостность загружаемого пакета проверяется до распаковки. Изображения входят в опубликованный сайт; браузер посетителя не обращается к старому хостингу.

Доступ к сайту не требует аккаунта GitHub. Исходные файлы в публичном репозитории будут общедоступны; личный экспорт деревни в них не включён.

## Перенос прогресса

Браузер хранит данные отдельно для каждого домена. На новом адресе повторно импортируй JSON из игры или экспорт снимка со старого сайта. Старый сайт не нужно отключать до проверки нового адреса.
