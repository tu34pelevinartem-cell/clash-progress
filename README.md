# Clash Progress

Статический трекер прогресса Clash of Clans. Сайт работает без сервера и регистрации. Снимки деревни сохраняются в браузере посетителя.

## Снаряжение

Раздел `#equipment` показывает предметы компактно: изображение, текущий и целевой уровни, остаток каждого вида руды. Общий бюджет виден сверху; фильтры по героям и сортировка помогают выбрать следующий предмет. Бюджет охватывает только предметы из JSON с доступными данными для выбранной цели. В подробностях сумма оставшихся затрат показана над таблицей уровней; мгновенные улучшения не выводят нулевые таймеры. Виды руды считаются отдельно.

## Стены и ресурсы

Раздел `#walls` считает стоимость всех переходов от уровней секций в JSON до выбранного уровня. Учитываются количество секций, предел текущей ратуши или Дома строителя, Gold Pass и выбранная скидка события. Для шагов с альтернативной оплатой показывается один бюджет «золото или эликсир»; он не суммируется дважды. Стоимость с событием предполагает, что выбранные стены будут оплачены во время его действия. Стены не добавляют время в очередь строителей.

## Ускорения и зелья

В `#forecast` сравниваются базовый прогноз, ежедневная помощь с событием и тот же сценарий с расходуемыми зельями. Настройки сохраняются отдельно для основной деревни и деревни строителя. Прогноз предполагает непрерывную работу, доступные ресурсы, готовые ускорения в начале сценария и немедленный запуск следующего улучшения. Эффект зелий показан отдельно для каждой очереди и общей даты: ускорение короткой очереди может не изменить срок фулла.

Скидки на новые улучшения перемножаются. Текущие таймеры из JSON не получают скидку повторно. Временное событие применяется к улучшениям, начатым до конца указанного периода. Hammer Jam 2026 — отдельная настройка 50% для основной деревни до 16 ноября 08:00 UTC; 75% — пользовательский сценарий. Gold Pass в прогнозе предполагается постоянным на выбранном уровне бонуса.

Эквивалент прогресса от зелий — дополнительный объём работы в единицах базового времени справочника. Он не меняет уровни и фактический прогресс деревни. При импорте нового снимка количества запланированных зелий сбрасываются, чтобы уже использованные предметы не учитывались повторно.

Правила ускорений: [помощники](https://support.supercell.com/clash-of-clans/en/articles/helpers-2.html), [магические предметы](https://support.supercell.com/clash-of-clans/en/articles/magic-items-and-the-trader.html), [Часовая башня](https://supercell.com/en/games/clashofclans/blog/news/builder-base-news-2/), [Hammer Jam 2026](https://supercell.com/en/games/clashofclans/blog/news/hammer-jam-is-here-backup-has-arrived/).

## Clash Coach

Раздел `#coach` подбирает учебные стратегии по текущему экспорту: доступные войска и заклинания, уровни относительно лимита ратуши, вместимость лагерей и готовность героев. Показатель готовности — прозрачная оценка уровней, а не вероятность победы. Алгоритм не обучался на матчах киберспортсменов и не видит расстановку противника.

Разбор повтора работает локально: выбранное видео воспроизводится в браузере, пользователь добавляет заметки с таймкодами и экспортирует их. Сайт не отправляет видео, JSON деревни и заметки на сервер. Сам видеофайл не сохраняется между перезагрузками — для восстановления заметок выбери тот же файл. Автоматический анализ видео моделью пока не подключён.

## Публикация на GitHub Pages

Репозиторий использует GitHub Actions: изменения в main собирают и публикуют сайт автоматически. В Settings → Pages выбран источник GitHub Actions.

Скрипт scripts/prepare-assets.cjs собирает каталог _site: распаковывает справочник data/upgrades.json.gz и добавляет изображения из закреплённой версии clash-of-clans-data. Целостность загружаемого пакета проверяется до распаковки. Изображения входят в опубликованный сайт; браузер посетителя не обращается к старому хостингу.

Доступ к сайту не требует аккаунта GitHub. Исходные файлы в публичном репозитории будут общедоступны; личный экспорт деревни в них не включён.

## Перенос прогресса

Браузер хранит данные отдельно для каждого домена. На новом адресе повторно импортируй JSON из игры или экспорт снимка со старого сайта. Старый сайт не нужно отключать до проверки нового адреса.

## Данные и изображения

Изображения ратуш, зданий, стен и войск выбираются по текущему уровню из импорта. Цель прокачки не меняет внешний вид существующих объектов. В расчёте стен показаны изображения каждой группы текущих уровней и отдельно подписанная картинка выбранной цели. Сборка добавляет соответствия уровней изображениям из закреплённого пакета; одинаковые модели соседних уровней используют один файл. Герои, снаряжение и объекты без отдельных моделей используют общую иконку. Неизвестный уровень не получает изображение максимального уровня.
