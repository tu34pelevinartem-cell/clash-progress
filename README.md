# Clash Progress

Статический трекер прогресса Clash of Clans. Сайт работает без сервера и регистрации. Снимки деревни сохраняются в браузере посетителя.

## Читаемый интерфейс

Основной текст увеличен до 16px; подписи, карточки и кнопки стали крупнее. На телефоне раздел выбирается в обычном меню рядом с логотипом. Внутри разделов нет повторной общей сводки, а каталог новинок и методика раскрываются по запросу. Главная показывает профиль деревни, прогноз и прогресс. JSON можно вставить или выбрать файлом в одном окне «Обновить данные».

## Обновление ТХ19 · 16 ноября 2026

Оформление обновлено под камень, латунь и золото ТХ19. Релизная база ClashKing Assets 2.5.0 от 16 ноября закрывает все 98 новых уровней и добавляет 17 сущностей с настоящими игровыми ID: четыре здания, заклинание и 12 отрядов. Ревизия данных: `2026-11-16-th19-release`.

Все 83 прежних пропуска цен и сроков заполнены релизными значениями. Дополнительная сверка внесла 13 подтверждённых корректировок старых уровней основной деревни: зал героев 1, адская башня 5, Король варваров 83–89, пускатель войск 3, бомба 4, воздушная мина 3 и торнадо 1. Остальные 3152 старые цены и сроки сохранены, включая уже применённые сокращения; повторная скидка к ним не применяется. Специальные случаи деревни строителя и два сомнительных нулевых таймера источника не переносились. У войск, героев, питомцев и стражей исходные `upgrade_cost/time` относятся к следующему уровню, поэтому при переносе сдвинуты на один уровень. Ноль на последнем уровне источника не означает бесплатный переход к максимуму.

Новые здания распознаются в `buildings`, отряды — в `units`, стражи — в `guardians`. Стражи используют очередь строителей. Фиксированное святилище без `lvl` распознаётся как построенный объект уровня 1; это правило не применяется к другим объектам с неизвестным уровнем. Прогноз по-прежнему охватывает объекты из импорта и выбранный ручной план, без автоматического создания отсутствующих построек.

В разделах зданий и армии есть каталог двух новых башен, святилища стражей, казармы отрядов и героического заклинания. В раскрытых карточках — опубликованные уровни, цены и сроки. Можно явно указать текущий уровень каждого нового объекта или выбрать «Не построено»: оставшаяся цепочка попадёт в общие очереди и бюджет. По умолчанию ручные объекты не включены. План хранится отдельно для каждого аккаунта и не меняет уровни, фактический процент и количество объектов из JSON. Уже распознанные постройки повторно не добавляются. Игровые изображения и их источники перечислены в [RELEASE-ASSETS.md](RELEASE-ASSETS.md).

## История и карточка прогресса

История показывает конкретные изменения между выбранными снимками: уровни зданий, героев, войск, снаряжения и распределение секций стен. Добавления и исчезновения объектов показаны отдельно от улучшений: слияние не считается потерей прогресса. Истёкший таймер не подтверждает новый уровень. Сохраняется до 30 предыдущих снимков; при нехватке места сначала удаляются самые старые записи.

Кнопка «Поделиться» создаёт PNG 1080×1080 с текущей ратушей, героями, процентом, датой снимка и прогнозом. Тег аккаунта скрыт по умолчанию. Можно скачать картинку, отправить её системным меню либо скопировать обычную ссылку на сайт. Снимок и ручные настройки не отправляются на сервер и не включаются в ссылку.

## Возможная автоматическая синхронизация

Текущая версия хранит историю и настройки на устройстве. Для истории между устройствами понадобится отдельный сервер, база и вход пользователя. Привязку игрового аккаунта можно подтверждать игровым API-токеном через `/players/{playerTag}/verifytoken`; серверный ключ API не должен попадать в статические файлы GitHub Pages.

API профиля позволяет обновлять армию, героев и снаряжение, но не сообщает уровни зданий, стен и их текущие таймеры. База данных не устраняет это ограничение: для этих разделов нужны новые экспорты либо ручные изменения. Автоматически повышать уровень по истечении таймера нельзя считать подтверждённым игровым прогрессом. См. [модель профиля API](https://clashofclans.js.org/docs/api/interfaces/APIPlayer) и [проверку токена](https://clashofclans.js.org/docs/api/interfaces/APIVerifyToken).

## Снаряжение

Раздел `#equipment` показывает предметы компактно: изображение, текущий и целевой уровни, остаток каждого вида руды. Общий бюджет виден сверху; фильтры по героям и сортировка помогают выбрать следующий предмет. Бюджет охватывает только предметы из JSON с доступными данными для выбранной цели. В подробностях сумма оставшихся затрат показана над таблицей уровней; мгновенные улучшения не выводят нулевые таймеры. Виды руды считаются отдельно.

Отсутствующие в полном разделе снаряжения предметы обозначаются «Нет на аккаунте», в подробностях — уровнем 0. Они не входят в бюджет руды. Настоящий уровень 1 сохраняется; отсутствие самого раздела в JSON означает неизвестные данные. Исправлено соответствие ID Electro Fangs (`90000059`) и Monolith Arrow (`90000016`); текущий уровень берётся из экспорта.

Эпический предмет с уровнем 1 в экспорте не считается доказанно полученным: такой же уровень может быть у отсутствующего предмета. Карточка просит подтвердить наличие. В подробностях можно выбрать «Есть, уровень 1» либо «Нет на аккаунте»; выбор хранится на устройстве отдельно для каждого аккаунта, исходный JSON не меняется. Неподтверждённые и отсутствующие предметы не входят в бюджет руды. Уровень выше 1 из нового экспорта подтверждает наличие и имеет приоритет над старой отметкой отсутствия.

## Стены и ресурсы

Раздел `#walls` считает стоимость всех переходов от уровней секций в JSON до выбранного уровня. Учитываются количество секций, предел текущей ратуши или Дома строителя, Gold Pass и выбранная скидка события. Для шагов с альтернативной оплатой показывается один бюджет «золото или эликсир»; он не суммируется дважды. Стоимость с событием предполагает, что выбранные стены будут оплачены во время его действия. Стены не добавляют время в очередь строителей.

Для ТХ19 учитывается ограничение: до уровня 20 можно улучшить 150 секций, включая уже готовые. Сначала выбираются стены с самым высоким текущим уровнем; оставшиеся считаются до уровня 19. Новые секции, которых ещё нет в JSON, не создаются автоматически.

## Ускорения и зелья

В `#forecast` показаны два срока: базовый (с выбранным Gold Pass, если он есть) и с остальными ускорениями. Бонусы на каждый день и зелья из запаса разделены; подробности очередей и методика свёрнуты. Настройки сохраняются отдельно для основной деревни и деревни строителя. Прогноз предполагает непрерывную работу, доступные ресурсы и немедленный запуск следующего улучшения. Ускорение короткой очереди может не изменить срок фулла; блок klimat отдельно показывает срок лаборатории и экономию именно от еженедельных покупок.

Скидки на новые улучшения перемножаются. Текущие таймеры из JSON не получают скидку повторно. Hammer Jam закончился 16 ноября: скидки событий по умолчанию отключены, включая ранее сохранённые настройки времени и стен. Варианты 50% и 75% остаются для явного ручного сценария с выбранной длительностью; новые ручные настройки сохраняются. Gold Pass в прогнозе предполагается постоянным на выбранном уровне бонуса.

Блок «Специально для игрока klimat» добавляет покупку трёх зелий лаборатории каждые семь дней. Первая будущая партия поступает через семь дней от начала прогноза; уже имеющиеся зелья задаются отдельно. Каждое зелье даёт час работы в 24 раза быстрее. Покупки не выдаются все сразу, помощник прибавляет свою скорость, а не умножается на зелье. Учитываются только зелья, начатые до завершения исследований. Это пользовательский сценарий регулярных покупок, доступность и расход валюты магазина не моделируются.

Эквивалент прогресса от зелий — дополнительный объём работы в единицах базового времени справочника. Он не меняет уровни и фактический прогресс деревни. При импорте нового снимка количества запланированных зелий сбрасываются, чтобы уже использованные предметы не учитывались повторно.

Правила ускорений: [помощники](https://support.supercell.com/clash-of-clans/en/articles/helpers-2.html), [магические предметы](https://support.supercell.com/clash-of-clans/en/articles/magic-items-and-the-trader.html), [Часовая башня](https://supercell.com/en/games/clashofclans/blog/news/builder-base-news-2/), [Hammer Jam 2026](https://supercell.com/en/games/clashofclans/blog/news/hammer-jam-is-here-backup-has-arrived/).

## Clash Coach · временно скрыт

Раздел временно выключен: кнопка, маршрут и подключения его скриптов убраны. Исходные файлы сохранены, чтобы вернуть тренера позже. Старые ссылки `#coach` открывают обзор деревни.

Раздел `#coach` подбирает учебные стратегии по текущему экспорту: доступные войска и заклинания, уровни относительно лимита ратуши, вместимость лагерей и готовность героев. Показатель готовности — прозрачная оценка уровней, а не вероятность победы. Алгоритм не обучался на матчах киберспортсменов и не видит расстановку противника.

Разбор повтора работает локально: выбранное видео воспроизводится в браузере, пользователь добавляет заметки с таймкодами и экспортирует их. Сайт не отправляет видео, JSON деревни и заметки на сервер. Сам видеофайл не сохраняется между перезагрузками — для восстановления заметок выбери тот же файл. Автоматический анализ видео моделью пока не подключён.

## Публикация на GitHub Pages

Репозиторий использует GitHub Actions: изменения в main собирают и публикуют сайт автоматически. В Settings → Pages выбран источник GitHub Actions.

Скрипт scripts/prepare-assets.cjs собирает каталог _site: распаковывает справочник data/upgrades.json.gz и добавляет изображения из закреплённой версии clash-of-clans-data. Целостность загружаемого пакета проверяется до распаковки. Изображения входят в опубликованный сайт; браузер посетителя не обращается к старому хостингу.

Доступ к сайту не требует аккаунта GitHub. Исходные файлы в публичном репозитории будут общедоступны; личный экспорт деревни в них не включён.

## Перенос прогресса

Браузер хранит данные отдельно для каждого домена. На новом адресе повторно импортируй JSON из игры или экспорт снимка со старого сайта. Старый сайт не нужно отключать до проверки нового адреса.

## Данные и изображения

Изображения ратуш, зданий, стен и войск выбираются по текущему уровню из импорта. Цель прокачки не меняет внешний вид существующих объектов. В расчёте стен показаны изображения каждой группы текущих уровней и отдельно подписанная картинка выбранной цели. Сборка добавляет соответствия уровней изображениям из закреплённого пакета; одинаковые модели соседних уровней используют один файл. Герои, снаряжение и объекты без отдельных моделей используют общую иконку. Неизвестный уровень не получает изображение максимального уровня.
